# RÜdex

Registro y catálogo de aves en terreno para la Región de O'Higgins. Aplicación web instalable que funciona sin conexión.

Incluye el formato de la Ficha de Caracterización de Avifauna utilizada por el SAG y exporta en esa estructura.

Aplicación: https://ivan-salgado.github.io/rudex/
